# 클라이언트 답변으로 확인한 가정

> 제안서 Ⅶ-18 질문 1~3의 클라이언트 답변을 바탕으로, 제안서 Ⅶ-16과 1~4단계 `[가정]`·`[추정]` 중 확인된 것과 남은 것을 정리합니다.
> 여기서 `[사실]`은 자료 원문이 아니라 **클라이언트가 직접 말한 것**입니다. 답변은 광고 1건·1명 기준이라 일반화하지 않습니다. 질문 2는 클라이언트 지인(소상공인)의 사례라 간접 근거입니다.

## 받은 답변 (요약)

| 질문 | 답변 |
| --- | --- |
| 1. 최근 광고·홍보 한 건의 순서와 가장 오래 걸린 곳 | 기획 1시간, 사진 촬영 2시간, 캡션 작성 2시간, 업로드 2시간(캡션 수정). 홍보비 10만원, 7일. 캡션·해시태그 초안에 집중하기를 원함(사진은 범위 밖). 광고로 생긴 수익 확인 기능, 셀러별 개인화 AI, 앞 광고의 좋은 결과를 다음 프롬프트에 반영하는 방식을 원함 |
| 2. 게시 전 확인 기준과 고치거나 내린 경우 | 본인은 답하기 어려움. 직접 마케팅하는 지인(소상공인)이 플랫폼에 걸릴까 봐 밋밋한 표현을 써서 아쉬워함. 대체 표현을 추천하고, 표현을 고칠 때 기사 등 근거 자료를 함께 보여 주면 좋겠다고 함 |
| 3. 광고 게시·예산 집행 주체와 서비스가 맡을 범위 | 사용자는 글을 쓰고 검증하는 부분만 맡으면 좋겠음. 홍보 버튼은 사용자가 직접 누름 |

## 확정된 것 (태그를 [사실]로 올린 항목)

- **광고 1건 콘텐츠 준비 시간의 '지금' 값 (제안서 Ⅴ 지표)**: 기획 1h, 사진 촬영 2h, 캡션 작성 2h, 업로드 2h(캡션 수정)로 총 7시간이다. 사진을 빼면 5시간이다. (클라이언트 답변 Q1)
- **가장 오래 걸리는 곳은 캡션 작성·수정 (제안서 As-Is 2번, 02 흐름 A 3번)**: 7시간 중 4시간이다. (클라이언트 답변 Q1)
- **F-01 범위**: 캡션·해시태그 초안에 집중하고, 사진은 범위 밖으로 둔다. (클라이언트 답변 Q1)
- **핵심 대상은 광고 단위 (제안서 Ⅶ-16, 03 3-2)**: 광고 한 건 단위로 진행한다. 다만 앞 광고의 성과를 다음 광고에 반영하는 연결이 필요하다. (클라이언트 답변 Q1)
- **광고 예산 규모 (제안서 고객사 설정 2 일부)**: 홍보 1건에 10만원을 쓰고 7일 동안 집행한다. (클라이언트 답변 Q1)
- **승인 전에는 게시·집행하지 않음 (03 R6, 제안서 Ⅶ-16)**: 홍보 버튼은 사용자가 직접 누른다. 사용자는 글쓰기와 검증을 맡는다. (클라이언트 답변 Q3)
- **광고비 효과를 판단할 수단이 없음 (제안서 해결할 문제)**: 광고로 수익이 얼마나 났는지 확인하는 기능을 요청했다. (클라이언트 답변 Q1)
- **표현 검수가 필요함 (제안서 문제 정의, 간접 근거)**: 셀러가 플랫폼에 걸릴까 봐 밋밋한 표현을 쓴다. 대체 표현 추천과 근거 자료(기사 등) 제시를 원한다. (클라이언트 지인 사례 Q2)
- **새 요구**: 셀러별 개인화 AI, 앞 광고의 성과를 다음 프롬프트에 반영하는 피드백 루프. (클라이언트 답변 Q1)
