## 확정된 것 (태그를 \[사실\]로 올린 항목)

- **광고 1건 콘텐츠 준비 시간의 '지금' 값 (Ⅴ 지표)**: 기획 1h, 사진 촬영 2h, 캡션 작성 2h, 업로드 2h(캡션 수정)로 총 7시간이다. 사진을 빼면 5시간이다. (클라이언트 답변 Q1)
- **가장 오래 걸리는 곳은 캡션 작성·수정 (As-Is 2번, 02 흐름 A 3번)**: 7시간 중 4시간이다. (클라이언트 답변 Q1)
- **F-01 범위**: 캡션·해시태그 초안에 집중하고, 사진은 범위 밖으로 둔다. (클라이언트 답변 Q1)
- **핵심 대상은 광고 단위 (16, 03 3-2)**: 광고 한 건 단위로 진행한다. 다만 앞 광고의 성과를 다음 광고에 반영하는 연결이 필요하다. (클라이언트 답변 Q1)
- **광고 예산 규모 (고객사 설정 2 일부)**: 홍보 1건에 10만원을 쓰고 7일 동안 집행한다. (클라이언트 답변 Q1)
- **승인 전에는 게시·집행하지 않음 (R6, 16)**: 홍보 버튼은 사용자가 직접 누른다. 사용자는 글쓰기와 검증을 맡는다. (클라이언트 답변 Q3)
- **광고비 효과를 판단할 수단이 없음 (해결할 문제)**: 광고로 수익이 얼마나 났는지 확인하는 기능을 요청했다. (클라이언트 답변 Q1)
- **표현 검수가 필요함 (문제 정의, 간접 근거)**: 셀러가 플랫폼에 걸릴까 봐 밋밋한 표현을 쓴다. 대체 표현 추천과 근거 자료(기사 등) 제시를 원한다. (클라이언트 지인 사례 Q2)
- **새 요구**: 셀러별 개인화 AI, 앞 광고의 성과를 다음 프롬프트에 반영하는 피드백 루프. (클라이언트 답변 Q1)

## 다음 미팅에서 물어볼 것

가정 표의 '언제 확인하나'가 다음 미팅인 항목을 MVP 범위에 미치는 영향이 큰 순서로 묶었습니다.

### 1. MVP 범위를 좌우하는 것 (먼저)

1. 게시와 집행은 사용자가 직접 하신다고 했는데, 게시 예약이나 자동 집행이 있다면 쓰시겠습니까? 외부 연동은 '게시'가 아니라 '성과 받아 오기'만 해도 충분합니까? (게시 예약됨 → 집행중 자동 전환, F-03·F-04, R7)
2. 광고를 올리는 채널은 어디입니까? 인스타그램·X·틱톡이 맞습니까? (고객사 설정 2, 초안 형식·심사 규칙·연동 대상)
3. 요청하신 '수익'은 수수료·광고비·배송비·원가를 뺀 실제 이익입니까, 광고 매출이나 ROAS입니까? (F-05, F-07)

### 2. 사용자와 문제 정의를 확인하는 것
