## 핵심 대상과 정상 경로

핵심 대상은 광고 한 건을 관리하는 캠페인이다.

기획중 → 초안 생성됨 → 검수 대기 → 승인됨 → 게시 예약됨 → 집행중 → 종료 → 성과 평가 완료

| 순서 | 누가 | 무엇을 하는가 | 이때 상태 | LLM 관여 | 스토리 |
| --- | --- | --- | --- | --- | --- |
| 1 | 사용자 | 상품명·특징·가격·목표·채널·예산을 입력·저장한다 | 기획중 | 없음 | US-01 |
| 2 | 사용자 요청·시스템 | 인스타그램·X·틱톡 중 선택한 채널의 캡션·해시태그 초안을 생성한다 | 초안 생성됨 | L1 초안 | US-01 |
| 3 | 사용자 요청·시스템 | 문구를 확인·수정하고 검수를 요청한다. 위험 표현·이유·근거·대체 문구를 보여 준다 | 검수 대기 | L2 검수 | US-02·US-03 |
| 4 | 사용자 | 필요하면 수정·재검수한다. 현재 문구의 검수가 완료되면 경고를 확인하고 승인한다 | 승인됨 | 승인 결정에는 없음 | US-03 |
| 5 | 사용자 | 게시 일정·예산을 저장한다. 24시간 이내 일정은 안내하되 저장을 허용한다 | 게시 예약됨 | 없음 | US-04 |
| 6 | 사용자 | 외부 플랫폼에 직접 게시한 뒤 ‘게시함’을 기록한다 | 집행중 | 없음 | US-07 |
| 7 | 사용자 | 외부 플랫폼의 집행을 끝낸 뒤 ‘종료’를 기록한다 | 종료 | 없음 | US-07 |
| 8 | 사용자 입력·시스템 | 노출·클릭·전환·광고비·매출을 입력한다. 서버가 ROAS를 계산하고 요약·다음 광고 제안을 만든다 | 종료 | L3 요약 | US-05 |
| 9 | 사용자 | 요약을 확인하고 ‘평가 완료’를 누른다 | 성과 평가 완료 | 완료 결정에는 없음 | US-05 |

현재 공유 작업공간에서는 가장 최근 평가 완료 캠페인의 문구·성과·요약을 다음 초안에 참고한다. 보고서의 셀러별 개인화는 인증·계정별 저장을 다시 도입할 때 참고 범위도 함께 정한다.

## 수정·반려·취소 경로

| 상황 | 동작과 상태 | 스토리 |
| --- | --- | --- |
| 검수 경고 | 검수 대기를 유지한다. 사용자가 대체 문구를 적용·수정한 뒤 재검수하거나, 검수가 완료된 현재 문구를 승인한다 | US-03 |
| 플랫폼 반려 | 게시 예약됨 → 플랫폼 반려(사유 필수) → 사용자가 ‘다시 고치기’ → 수정 요청 → 수정·검수 요청 → 검수 대기 → 승인됨 → 재예약 | US-07·US-03·US-04 |
| 게시 전 취소 | 기획중·초안 생성됨·게시 예약됨 → 취소. 취소 후 변경·되돌림 불가 | US-06 |
| AI 호출 실패 | 오류와 재시도 동작을 제공한다. 검수 실패·처리 중에는 승인할 수 없고, 요약이 준비되지 않으면 평가를 완료할 수 없다 | US-01·US-03·US-05 |

## 시연과 구현 확인 범위

중간 미팅 보고서의 시연은 목업 데이터로 정상 흐름과 플랫폼 반려·취소를 보여 주는 계획이다. 현재 화면에는 실제 API 연결 코드가 있으며, 이번 문서 반영에서 실제 AI·DB·배포의 전체 흐름을 실행 검증하지는 않았다. 보고서 당시 현황과 현재 코드의 차이는 [반영 기록](../interview/mid-meeting-report.md#보고서-당시-현황과-현재-코드)을 따른다.

플랫폼 자동 게시·성과 자동 수집, 예산 소진에 따른 자동 종료·일시정지, 실제 이익 계산, 이미지 생성·인플루언서 추천은 이 흐름에 포함하지 않는다.
