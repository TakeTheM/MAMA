# 핵심 사용자 흐름

> **저장 위치:** `docs/requirements/user-flows.md`

> 첫 데모에서 보여줄 흐름을 **하나만** 정합니다. 어제 그린 상태 전이(`docs/domain/03-rules-states-llm.md` 3-2)를 **처음부터 끝까지 한 번 지나가는** 정상 경로여야 합니다. 이 흐름이 첫 데모(3주차)에서 보여줄 그 흐름입니다.
> 이 단계에서는 Claude를 쓰지 않습니다. `>`로 시작하는 안내 문장은 지워도 됩니다.

## 연결된 상태 전이

03-rules-states-llm.md의 핵심 대상:
지나가는 상태: A → B → C → D → … (4개 이상)

## 첫 데모에서 보여줄 흐름 (1개)

| 순서 | 누가     | 무엇을 하는가                     | 이때 상태      | LLM 관여 |
| ---- | -------- | --------------------------------- | -------------- | -------- |
| 1    | 소상공인 | 상품·목표·채널·예산을 입력함      | 초안 생성됨    | O        |
| 2    | 소상공인 | 초안 내용 검수                    | 초안 검수 대기 | X        |
| 3    | 시스템   | 금지 표현/논란 위험 표현 검토함   | 초안 표현 검수 | O        |
| 4    | 소상공인 | 채널별 게시 시간·광고 예산을 정함 | 초안 승인됨    | X        |
| 5    | 시스템   | 플랫폼 광고 개시                  | 집행 중        | O        |
| 6    | 시스템   | 광고 후 성과 평가 보고서 작성     | 성과 평가 완료 | O        |
