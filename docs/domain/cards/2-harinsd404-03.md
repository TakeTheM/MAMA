# 2-harinsd404-03 식품은 질병 예방·치료 효능, 식품·화장품은 의약품으로 오인될 광고 금지

| 항목 | 내용 |
| --- | --- |
| 관점 | ② 규칙·예외 |
| 자료 종류 | 법령 |
| 제목·저자(기관)·연도 | 식품 등의 표시ㆍ광고에 관한 법률 (법률 제20826호, 2025.9.19. 시행) / 화장품법 (법률 제21525호, 2026.10.8. 시행) · 국가법령정보센터 |
| 찾은 곳·링크 (DOI) | https://www.law.go.kr/법령/식품등의표시ㆍ광고에관한법률/제8조 · https://www.law.go.kr/법령/화장품법/제13조 |
| 직접 확인 | ☑ 직접 열어 확인함 (2026-10-13, 국가법령정보센터 원문) · 확인한 위치: 식품표시광고법 제8조 제1항 제1호~제4호, 화장품법 제13조 제1항 제1호·제2호·제4호 |
| 확인한 내용 | 식품표시광고법 제8조 ① "누구든지 식품등의 명칭ㆍ제조방법ㆍ성분 등 대통령령으로 정하는 사항에 관하여 다음 각 호의 어느 하나에 해당하는 표시 또는 광고를 하여서는 아니 된다. 1. 질병의 예방ㆍ치료에 효능이 있는 것으로 인식할 우려가 있는 표시 또는 광고 2. 식품등을 의약품으로 인식할 우려가 있는 표시 또는 광고 3. 건강기능식품이 아닌 것을 건강기능식품으로 인식할 우려가 있는 표시 또는 광고 4. 거짓ㆍ과장된 표시 또는 광고" <br> 화장품법 제13조 ① "영업자 또는 판매자는 다음 각 호의 어느 하나에 해당하는 표시 또는 광고를 하여서는 아니 된다. 1. 의약품으로 잘못 인식할 우려가 있는 표시 또는 광고 2. 기능성화장품이 아닌 화장품을 기능성화장품으로 잘못 인식할 우려가 있거나 … 4. 그 밖에 사실과 다르게 소비자를 속이거나 소비자가 잘못 인식하도록 할 우려가 있는 표시 또는 광고" |
| 우리 도메인에 주는 근거 한 줄 | 식품·화장품을 파는 소상공인의 광고 문구는 "치료", "예방"처럼 의약품으로 보일 표현을 쓰면 안 되므로, L2 검수에서 카테고리별 금지 표현을 걸러야 한다 |
| 태그 변화 | R4 `[추정]` → `[사실]` ("면역력에 좋은", "여드름 진정" 같은 개별 표현의 허용 여부는 총리령·고시 기준이라 `[추정]` 유지) |
