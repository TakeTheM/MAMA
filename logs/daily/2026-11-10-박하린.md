  - 진행 순서는 기획 → 초안(L1) → 검수(L2) → 직접 고치기 → 재검수 → 승인 → 게시 예약 → 게시함 → 종료 기록 → 성과 입력·요약(L3) → 평가 완료다.
  - 화면 아래에 단계별 자막을 넣고, 마우스 위치를 빨간 점으로 표시했다.
  - 초안에 "먹기만 해도 살이 쏙 빠지는… 업계 1위" 같은 위험 문장을 일부러 넣었다. 검수가 위험 표현 4개를 찾는 장면이 영상에 나온다.
- 녹화하면서 앱 문제 2가지를 찾았다.
  - 검수 결과의 '적용' 버튼을 누르면 문구가 망가진다. AI가 고친 문장 대신 "체중 감량 효능을 암시하는 표현을 빼고…" 같은 조언 문장을 돌려주고, 이 문장이 캡션에 그대로 들어간다. 그래서 영상에서는 '직접 고치기'로 위험 문장을 지웠다.
  - 검수 요청이 가끔 "검수 결과의 원문 위치를 확인할 수 없습니다"로 실패한다. AI가 준 글자 위치가 원문과 맞지 않으면 백엔드가 결과를 거절한다. 같은 입력으로 다시 녹화하니 성공했다.

## Claude가 제안했지만 고치거나 쓰지 않은 것

- Claude는 처음에 로컬 Docker Postgres와 로컬 FastAPI를 띄우고 LLM 키를 `backend/.env`에 넣어 녹화하자고 제안했다. 당시 로컬 백엔드는 아직 인증을 요구했으므로, 녹화할 때만 요청에 토큰을 붙이는 방법도 함께 제안했다. 이 방식은 쓰지 않고 배포된 백엔드로 녹화하게 했다.
- '적용' 버튼 문제와 검수 위치 오류는 영상에서 피해 가기만 했고, 코드는 고치지 않았다.
