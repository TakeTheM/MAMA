# F-05 성과 요약과 다음 광고 제안

종료 캠페인에서만 성과를 저장합니다. 광고 플랫폼 지표 자동 수집과 원가·수수료를 뺀 실제 이익 계산은 제외합니다.

| API (`/api/v1/campaigns/{id}` 기준) | 동작 |
| --- | --- |
| `PUT /performance` | 노출·클릭·전환·광고비·매출 저장, 시스템 ROAS 계산 후 AI 요약·제안 생성 |
| `GET /performance` | 저장된 입력·ROAS·요약·제안·오류·평가 완료 시각 조회 |
| `POST /summarize-performance` | 입력값을 유지한 채 요약 재시도 |
| `POST /complete-evaluation` | 요약 확인 후 사용자가 평가 완료 확정 |

입력 JSON은 `impressions`, `clicks`, `conversions`, `ad_spend`, `revenue`입니다. 전부 0 이상의 정수이며 금액 단위는 원입니다. ROAS는 매출 ÷ 광고비의 배수로 서버에서 계산하고 소수 6자리까지 보관합니다. JSON에서는 정확도를 위해 Decimal 문자열로 반환합니다. 광고비가 0이면 `roas: null`, `roas_display: "계산할 수 없음"`입니다.

숫자는 LLM 호출 전에 커밋합니다. LLM 실패 시 502·503·504를 반환해도 GET으로 입력 숫자와 ROAS를 볼 수 있으며 요약 재시도가 가능합니다. 숫자를 다시 저장하면 이전 요약을 무효화합니다. 이전 입력에 대한 늦은 결과는 revision 검증으로 거절합니다. 실행 중 프로세스가 종료되어도 180초 후 다시 요약할 수 있습니다.

요약 응답은 문자열 `summary`와 문자열 배열 `next_ad_suggestions`입니다. LLM에 지표 계산을 맡기지 않으며, LLM이 쓴 숫자로 시스템 지표를 덮어쓰지 않습니다. 화면에서 사용할 수치는 별도 숫자 필드를 기준으로 해야 합니다.

요약만 생성되어서는 여전히 종료 상태입니다. 사용자 확인으로 성과 평가 완료가 되어야 같은 셀러의 다음 F-01 초안에 가장 최근 평가 완료 캠페인의 문구·숫자·요약·제안이 들어갑니다. 참고 캠페인 ID는 초안 응답의 `reference_campaign_id`에 표시하고 LLM 요청에는 보내지 않습니다. 평가 완료 후 수치 수정·재요약은 막습니다.
