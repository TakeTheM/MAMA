# F-01 채널별 초안 생성

`POST /api/v1/campaigns/{id}/generate-draft`는 기획중 캠페인의 상품명·상품 설명·가격·목표·채널·최초 예산으로 초안을 생성합니다. 생성 결과는 자동으로 검수에 제출되지 않습니다.

- 등록·수정 필드: `product_name`, `product_description`, `product_category`, `product_price`, `goal`, `target_audience`, `channels`.
- 채널 값은 `instagram`, `x`, `tiktok`이며 중복은 허용하지 않습니다. 채널별 `drafts`에는 문자열 `caption`과 문자열 배열 `hashtags`를 저장합니다.
- `content`는 기존 API 호환을 위해 첫 번째 선택 채널의 캡션 문자열을 유지합니다. 광고 내용을 입력하지 않고 기획 데이터만으로 등록할 수 있습니다.
- LLM 설정은 `LLM_API_KEY`, `LLM_BASE_URL`(기본 OpenAI v1), `LLM_MODEL`, `LLM_TIMEOUT`입니다. 모델명은 임의로 고정하지 않습니다. 설정 누락 503, 응답 오류 502, 시간 초과 504이며 실패 시 기획 입력은 보존됩니다.
- LLM 응답은 JSON 모드와 서버 Pydantic 검증을 함께 사용합니다. 선택한 채널이 하나라도 빠지면 저장하지 않습니다.
- LLM을 기다리는 동안 DB 잠금을 유지하지 않습니다. 저장 시 상태·revision을 다시 확인해 취소·수정·다른 생성 요청 뒤 늦은 결과를 거절합니다.
- LLM 입력은 허용 필드만 구성하며 인증 정보·소유자 ID·고객 정보·원가는 전달하지 않습니다.

연결 규격: [OpenAI JSON mode](https://developers.openai.com/api/docs/guides/structured-outputs?api-mode=chat). 실제 모델과 학교 키의 사용 가능 여부는 환경 설정 후 확인해야 합니다.
